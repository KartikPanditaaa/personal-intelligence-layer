## The tension to resolve here

Memory is simultaneously the core differentiator and the core privacy risk.
[Open Questions](../01-problem-space/open-questions.md) asks both "What data
should be stored?" and "What data should never be stored?" — those two answers
define this section.

## What belongs here when it exists

- Memory taxonomy: what kinds of things are remembered
- Retention, decay, and forgetting
- Correction: what happens when a memory is wrong
- Inspection and export surfaces
- Scoping: per-project, per-workspace, cross-application
- The relationship between memory and [07-context](../07-context/README.md)

## Unanswered

- How should long-term memory work technically?
- How should cross-application context work?
- What data should be stored, and what should never be stored?
