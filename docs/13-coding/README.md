## The most contested surface

This is where competition is densest. Fourteen of the sixteen entries in
[16-competitive-analysis.md](../02-research/16-competitive-analysis.md) target
coding directly.

[Anti-Goals](../00-company/ANTI_GOALS.md) rules out competing here as an
autocomplete or an AI IDE. Whatever is built on this surface must be justified
against that constraint rather than against feature parity.

## What belongs here when it exists

- How memory and context change the coding experience specifically
- Where it sits relative to the tools developers already use
- The learning loop for code, the journey's final step, currently undefined
