# 08 UX Principles

## Decided

-   AI augments rather than replaces.
-   Trust over novelty.
-   Transparency.
-   User control.
-   Minimal cognitive interruption.
-   Personalization.
-   Human growth.
-   Inspectable memory.
-   Explainability.

## Requires founder decision

-   Visual language
-   Design system
-   Navigation
-   Accessibility targets
